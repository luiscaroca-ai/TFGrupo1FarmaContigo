Aviso de privacidad

Versión 2026-08-25. Este asistente registra un identificador seudónimo de sesión, tus preguntas, sus respuestas, la herramienta utilizada y la fuente consultada.

  • Finalidad: responder, mantener temporalmente el contexto y generar trazabilidad educativa.
  • Servicios utilizados: OpenAI para clasificar/redactar, Qdrant para consultar fichas y MINSAL para farmacias de turno.
  • Retención: conversaciones y registros expiran tras 24 horas de inactividad.
  • Evita datos personales: no ingreses RUT, correo, teléfono, domicilio ni nombres completos.
  • Borrado: puedes eliminar el contexto y los registros de esta sesión con “Borrar mis datos”.
